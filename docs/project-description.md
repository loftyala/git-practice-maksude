# Project Description

This project is a practice exercise for the Git & GitHub module. It is a small
command-line calculator written in Python, used as a vehicle for practicing
Git fundamentals: committing, branching, merging, and pushing to GitHub.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Division includes error handling for division by zero
- Demonstrates a full Git workflow: init, commits, branching, merging, and
  pushing to a remote GitHub repository
