# Git Practice - Maksude Ala

**Name:** Md. Maksude Ala

## What this project does

This is a practice project for learning Git and GitHub fundamentals. It contains a simple Python calculator program used to demonstrate:

- Local repository initialization
- Commits and commit history
- Branching and merging
- Pushing to a remote GitHub repository
- Basic error handling in Python
